# 🛡️ CyberShield SOC Dashboard

A modern, full-stack **Security Operations Center (SOC)** intelligence dashboard designed for fast network diagnostics, IP geolocation tracking, HTTP header security inspection, and password strength analysis.

![Dashboard Preview](https://img.shields.io/badge/Status-Active-brightgreen) ![Tech Stack](https://img.shields.io/badge/Stack-Node.js_%7C_Express_%7C_Leaflet.js-blue) ![License](https://img.shields.io/badge/License-MIT-yellow)

---

## 🚀 Key Features

- **🔍 Web Port Scanner:** Asynchronously scans target IPs or domains for open/closed TCP ports.
- **🔑 Password Strength Inspector:** Real-time entropy and complexity analysis for assessing password safety.
- **🌐 HTTP Header & Security Inspector:** Analyzes status codes, HTTPS encryption, server headers, HSTS, and X-Frame-Options.
- **🌍 IP Geolocation & Threat Map:** Integrates with IP intelligence APIs and renders interactive 2D maps via **Leaflet.js**.

---

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js, Net/HTTP modules.
- **Frontend:** HTML5, CSS3 (Cyberpunk / Dark Mode Theme with 3D Depth Shadows).
- **Mapping:** Leaflet.js / OpenStreetMap.
- **API:** IP-API (Geolocation).
